# 后端与维护说明

## 单条下载

1. 只提取抖音官方 HTTPS 链接，跟随短链后再次验证域名。
2. 从长链或分享页取得作品 ID，读取平台元数据。
3. 按 `play_addr_h264`、`play_addr`、H.264 码率源选择播放地址，不读取 `download_addr`，不靠替换 URL 文字伪造地址。
4. 使用脚本清理后的博主昵称建立目录，下载到 `.part`，完成后原子提交 MP4，不转码、不覆盖同名文件。
5. 优先用 ffprobe 校验时长、编码和音视频流；缺少时只做 MP4 文件头检查，不能回报未测得的媒体数据。

单条下载仍支持 Python 3.9+ 与 curl 的 macOS、Linux 和 Windows 环境。默认直连，不猜本机代理端口；用户可显式传 `--proxy` 或设置 `AH_DOUYIN_PROXY`。不安装证书，不修改系统代理。

## 两种转写交付

[单条逐字稿](single-transcript.md) 使用本地 MLX Whisper 生成临时机器文本与 SRT，由 Codex 完成整篇语义校对，最后只保留两份校对成品并清理受控临时目录。

[整号批量](creator-batch.md) 由 `run_creator.py` 调度：官方名片短链仅用于解析作者身份；专用正常 Edge 的网页 SDK 产生分页请求，采集公开响应的字段投影与游标链；使用本仓库下载器保存原片，再本地识别并保留机器 Markdown/SRT/证据。全量成功后由 `export_transcripts.py` 生成作者合集与 JSONL，不执行在线语义改写。

批量收尾在下载完成标记出现后重新读取最终下载清单，处理尚未尝试的已校验视频。原片或识别尚有缺失时不能报告全量成功，已完成项继续保留。

## 成本与私有数据

解析、下载、本地 ASR 和机器合集导出不使用付费解析、托管 ASR、在线 LLM 或模型 Computer Use。首次安装依赖和缓存模型需要网络；后续本地识别仍消耗计算、内存、磁盘和电量。Codex 的语义校对使用模型用量，批量全稿校对另计，不能笼统承诺整个 Skill 零 Token。

专用 Edge 会按正常浏览器行为保存本次登录。它的资料目录与可能的登录截图是私有运行数据，不打包进 Skill、不公开分享；不提取日常浏览器 Cookie，不保存请求头或完整签名 URL 到公开证据。正常沙箱、证书校验与密码存储保持启用，本机通道不进行 TLS 解密。

## 维护范围

只处理用户自有或已获授权的公开视频；作者硬水印、烧录字幕和贴片保留。图文、私密、已删除或不可访问作品不能冒称视频归档成功。博主昵称变更可能影响分类目录，以视频 ID 与检查点验收，不靠文件夹数量判断。

单条解析失败时先检查官方跳转、元数据字段和播放源，再用合成数据回归；不要默认改用未知解析站。批量失败先看实际阶段日志、目录分页链与缺失 ID。详细处置见 [troubleshooting.md](troubleshooting.md)。
