# Provenance

## Release scope

`ah-douyin-clean-downloader` was created for a local Codex workflow in which a
user supplies an authorized Douyin share command or official link and receives
the platform-provided playback file on their Desktop. Version 0.3.0 also accepts
an authorized creator profile/card and builds a resumable local video and raw
transcript library.

The first source-available release was prepared on 2026-09-20. The implementation
in `scripts/download_douyin.py`, the Skill instructions, tests, and release
documentation were written for this project. No upstream source files are
vendored in this repository. The creator-library scripts were developed and
tested locally in September 2026 and then consolidated into this stable Skill
entry point. They reuse the same downloader and cached Whisper model family.

## Consolidation on 2026-09-29

- Preserve the original single-video CLI and corrected Markdown/SRT workflow.
- Capture pagination generated by the official webpage SDK in an owned normal
  Edge session; no custom request-signing implementation is distributed.
- Add bounded original-video downloads, atomic checkpoints, local ASR, source
  and artifact hashes, a local index, and validated full-catalog exports.
- Label batch outputs as raw machine transcripts. Full semantic correction by
  the invoking model remains a separate task and consumes model tokens.
- Exclude experimental F2/DTK signers and daily-browser credential readers from
  the consolidated release.
- Apply the local `skill-creator` instructions to the router, progressive
  references, UI metadata, and validation. No Skill Creator source is bundled.

## Independent implementation decisions

- Accept only official `douyin.com` and `iesdouyin.com` links.
- Follow the share redirect and extract an item identifier.
- Read a Douyin-family metadata response and select H.264 playback sources.
- Do not select `download_addr` or any source explicitly marked as a watermarked
  download address.
- Download without transcoding and verify the resulting file locally.
- Avoid paid parsing APIs, exported login cookies, signature services, and
  visual inpainting. Optional creator collection uses normal login in its own
  private browser profile, never the user's daily browser credential database.

These statements describe repository evidence and engineering intent. They are
not an independent legal opinion about any platform interface or third-party
right.

## Excluded material

This repository does not contain:

- code or documentation copied from Yichen skills;
- source code from the four referenced repositories;
- real user videos, private share links, cookies, tokens, or account data;
- Douyin application binaries, signing implementations, or access-control
  bypasses;
- an AI model for removing hard-coded logos, subtitles, or overlays.
