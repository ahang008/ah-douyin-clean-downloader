# 整号批量能力合并设计

用户已确认：保留 `ah-douyin-clean-downloader` 稳定入口，把整号下载与本地转写合并到现有 Skill。

- 单条链接仍默认下载原片，保持现有命令和目录行为。
- 单条逐字稿仍由本地 ASR 生成草稿，再由调用 Skill 的模型完整校对 Markdown 与 SRT；验收后清理临时文件。
- 整号模式使用专用正常 Edge 窗口，由网页 SDK 获取公开作品分页。用户处理正常扫码登录；程序不读取日常浏览器账号数据库、不自动确认系统安全对话框。
- 下载复用同包下载器，转写使用缓存的 MLX Whisper，保留原片、机器 MD/SRT、识别证据、索引和完整合集。主流程不调用在线语言模型、视觉模型或付费 ASR。
- 完成必须同时满足完整分页目录、全部视频已验证、全部稿件保存。完整合集额外校验来源和成品哈希；样本或失败不能报告整号完成。
- 代码、指令、测试与许可证可以发布。浏览器登录目录、视频、逐字稿、模型和运行日志不得进入发布包。

采用 Skill Creator 的渐进式加载结构：入口只负责选择模式，单条校对和整号运行的详细说明分别进入 references。原单条命令不变，新增命令只依赖同包资源。

发布前验证旧下载/校对行为、浏览器分页边界、并行转写结束时的最后一次 manifest 扫描、完整合集验收，以及脱离本机 Skill 的独立发布包运行。
